# Скриншотер активного окна по клавише Home

Простая программа на чистом Python (без сторонних библиотек), которая делает скриншот **активного окна** при нажатии клавиши **Home** и сохраняет его в формате PNG рядом с самим скриптом.

## Возможности

- Скриншот только активного окна (не всего экрана)
- Сохранение в PNG
- Работает без установки дополнительных библиотек
- Имя файла содержит дату и время
- Минимальное потребление ресурсов

## Требования

- Windows
- Python 3.6 или новее

## Запуск

1. Сохрани скрипт как `screenshot_home.py`
2. Запусти его (желательно от имени администратора):

```bash
python screenshot_home.py
